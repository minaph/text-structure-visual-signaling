# text-structure-visual-signaling

日本語を中心とする文書の**意味構造を、読者に見える文字・記号・空白・配置によって標識する**ための独立したエージェントスキルです。研究ノート、調査報告、技術文書、手順書、メモ、チャット、メールなどの作成・推敲に適用できます。

対象は、`■`、`◇`、`※`、`【】`、番号、ラベル、空行、改行、字下げなど、**最終表示に残る視覚的手掛かり**です。Markdown の `#` や `*` など、パーサーによって別の構造に変換される構文そのものを規定するスキルではありません。

## 背景

このスキルは、**ChatGPT Deep Research による実証研究・情報デザイン論・スタイルガイドの調査**を出発点として設計しました。重要な区別は、〈構造を視覚的に区別すると理解や探索を支え得る〉という比較的安定した知見と、〈どの字形をどの階層に割り当てるか〉という媒体・文化・組織に依存する選択を分離することです。

`SKILL.md` は、文献レビュー自体ではなく、複数の知見と矛盾しにくい判断を**意味構造の抽出 → 視覚的機能の割当て → 最小限の差異化 → 一貫性・可搬性の検証**という実務手順へまとめています。`■` は必ず上位見出し、`◇` は必ず下位見出し、という固定対応は採用しません。

文献と各スタイルガイドの適用範囲、実証的裏付けの強弱、採用した原則と文脈依存のバリエーションは、[調査報告](docs/research-report.md) に記録しています。報告に掲載された初期の長文スキル案は設計過程の資料であり、運用時はルートの `SKILL.md` を正本としてください。

## 利用

[SKILL.md](SKILL.md) がエージェント用の実行指針です。リポジトリをスキル探索先へ配置するか、チェックアウトへのシンボリックリンクを登録してください。別のスキルへ組み込む場合は Git サブモジュール等で利用版を固定できます。

[evidence-based-writing](https://github.com/minaph/evidence-based-writing) と併用する場合、文章の**中心命題・根拠・論理関係・用語**は `evidence-based-writing` で検査し、完成した**意味構造の視覚的な標識・再現性・読み上げ耐性**を本スキルで検査します。見た目を整えるために、確定済みの主張内容や証拠を改変しません。

特定の組織、出版者、学会、法令等の指定スタイルがある場合は、適用範囲を確認したうえでその規約を優先します。重要な意味を記号の形だけに依存させないというアクセシビリティ上の原則は、例外適用時にも点検します。
